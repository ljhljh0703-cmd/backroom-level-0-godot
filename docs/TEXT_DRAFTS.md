# Text Drafts

게임 내 캡션/프롬프트 초안이다. 아직 확정 문구가 아니며, 사용자가 첨삭한 뒤 `data/rooms.json`과 `src/Game.gd`에 반영한다.

## 작성 원칙

- 한 줄은 짧게 유지한다.
- 상황 설명보다 플레이어가 느끼는 위화감을 우선한다.
- 시스템 문구처럼 말하지 않는다.
- 정답을 직접 알려주지 않는다.

## 방 캡션 초안

| 위치 | 초안 |
| --- | --- |
| `fork_stop` | 표지판 뒤가 비어 있다. |
| `fork_stop` 크리처 이후 | 방금 저 뒤에 뭔가 있었다. |
| `stop_back_space` 첫 진입 | 아무것도 보이지 않는다. |
| `stop_back_space` 붉어진 뒤 | 불길하다. |
| `left_blood_path` | 핏자국 같은 게 왼쪽으로 나있다. |
| `left_switch_room` | 벽에 전등 버튼이 하나 있다. |
| `right_panel_path` | 어째선지 이쪽 바닥은 너무 깨끗하다. |
| `right_dead_end` | 길이 끊겼다. |
| `blocked_passage` | 뒤가 막혔다. |
| `true_exit_room` | 나갈 수 있을 것 같다. |

## 조사/이벤트 캡션 초안

| 이벤트 | 초안 |
| --- | --- |
| STOP 표지 조사 | 글자가 칠해진 게 아니라 파여 있다. |
| 핏자국 조사 | 자국은 왼쪽에서 끊겨있다. |
| 전등 버튼 | 무언가 변한 것 같다. |
| 인간형 판넬 조사 A | 이런 곳에 어째서? |
| 인간형 판넬 조사 B | 눈을 마주친 것 같다. |
| 인간형 판넬 조사 C | 단순한 판넬인 것 같다. |
| 우측 막다른 벽 | 길이 끊겼다. |
| 막다른 길 복귀 | 판넬 뒤에서 소리가 났다. |
| STOP 뒤 첫 어둠 재조사 | 아무것도 없는 것 같다. |
| 반복 조사 | 아무것도 움직이지 않는다. |

## 엔딩 문구 초안

| 엔딩 | 캡션 | 프롬프트 |
| --- | --- | --- |
| A | 드디어. 돌아왔다. | A 엔딩: 진짜 출구. 클릭하면 다시 시작. |
| B | 나간 줄 알았다. | B 엔딩: 다시 백룸. 클릭하면 다시 시작. |
| C | 돌아보면 안 됐다. | C 엔딩: 크리처에게 잡힘. 클릭하면 다시 시작. |
